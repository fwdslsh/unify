This file holds only what you see here. The nav above comes from site/_layout.html, which wrapped this page at build time; the footer below is this page's own, addressed to the layout's named slot.

The site name and the footer's mailbox are placeholders — replace them before you publish.

To add a page, copy site/_examples/contact.html into site/, edit the copy, and list it in site/_includes/nav.html so readers can reach it. Give each new page its own <title>, its own description, and one <h1> — unify audit reports every page that is missing one or has more than one. Nothing under _examples/ ships, and unify update never touches a file you copied.

To change the look, edit site/assets/theme.css: the custom properties the stylesheet reads, each at its default. unify.yaml lists it under keep:, so unify update never overwrites it.
