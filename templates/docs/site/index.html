How this site is put together

Both guide pages are ordinary Markdown files in site/guide/, and neither one says anything about a layout. unify looks for _layout.html in a page's own folder and then in each folder above it, so the layout at the source root wraps pages a level down without being asked. Put a _layout.html in site/guide/ and every page under it uses that one instead — written out in full, because layouts do not chain.

Add a page by dropping a .md or .html file beside them and linking it from this list, or from site/_includes/nav.html to put it in the nav on every page. unify audit reports a page nothing links to, along with any page missing a title, a description, or a heading.
