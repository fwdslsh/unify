Overview

The documentation home for your project — replace this. Everything you can read on this site is scaffolding: replace the words, keep the shape.

The guide

Guide pages live in site/guide/, one Markdown file each. Start one by copying site/_examples/guide-page.md there under the name you want in its address, editing the copy, and linking it from this page or from site/_includes/nav.html. Nothing under _examples/ ships, and unify update never touches a file you copied. All pages lists every page the build publishes.

To change the look, copy site/_examples/theme.html to site/_includes/theme.html and edit the values: the layout includes that file, and your copy takes the place of the template's default.

How this site is put together

A guide page says nothing about a layout. unify looks for _layout.html in a page's own folder and then in each folder above it, so the layout at the source root wraps pages a level down without being asked. Put a _layout.html in site/guide/ and every page under it uses that one instead — written out in full, because layouts do not chain.

unify audit reports a page nothing links to, along with any page missing a title, a description, or a heading.
