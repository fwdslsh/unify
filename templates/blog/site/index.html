A blog scaffold: a posts/ folder, and one script, run by unify on every build, that turns whatever is in it into a listing page. Build with your address (see DEPLOY.md) and unify writes an Atom feed and a sitemap from the same posts, with nothing to run. The site name and the byline are placeholders — replace them before you publish.

The first post

Copy site/_examples/post.md into site/posts/ under the name you want in its address, and site/_examples/authors.json to site/_data/authors.json with your own name in it. Edit the copies: nothing under _examples/ ships, and unify update never touches a file you copied.

One of these pages is generated

blog.html is written by scripts/gen.mjs from the posts unify has already read and site/_data/authors.json, into a directory unify hands it before every build — it does not exist in site/. Build from the project root, the directory site/, scripts/ and unify.yaml sit in:

unify build
