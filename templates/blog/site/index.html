A blog scaffold: two sample posts in posts/, and one script, run by unify on every build, that turns them into a listing page and an RSS feed. Every name and date in it is a placeholder — replace them before you publish.

Read the blog index, open the first post, or get in touch.

Two of these files are generated

blog.html and feed.xml are written by scripts/gen.mjs from the posts and site/_data/authors.json, into a directory unify hands it before every build — neither exists in site/. Edit the posts and the data, and build from the project root, the directory site/, scripts/ and unify.yaml sit in:

unify build
