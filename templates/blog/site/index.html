A blog scaffold: a posts/ folder, and one script, run by unify on every build, that turns whatever is in it into a listing page and an RSS feed. The site name and the byline are placeholders — replace them before you publish.

The first post

Copy site/_examples/post.md into site/posts/ under the name you want in its address, and site/_examples/authors.json to site/_data/authors.json with your own name in it. Edit the copies: nothing under _examples/ ships, and unify update never touches a file you copied.

Two of these files are generated

blog.html and feed.xml are written by scripts/gen.mjs from the posts and site/_data/authors.json, into a directory unify hands it before every build — neither exists in site/. Build from the project root, the directory site/, scripts/ and unify.yaml sit in:

unify build
