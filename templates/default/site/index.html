This content lands in the layout's <main>. The nav above comes from site/_layout.html, which wrapped this page at build time; the footer below is this page's own, addressed to the layout's named slot.

The site name and the footer's mailbox are placeholders — replace them before you publish.

To add a page, copy one out of site/_examples/ — about.md, a Markdown page, or contact.html, an HTML page — into site/, edit the copy, and link it from site/_includes/nav.html. Nothing under _examples/ ships, and unify update never touches a file you copied.

To change the look, copy site/_examples/theme.html to site/_includes/theme.html and edit the values: the layout includes that file, and your copy takes the place of the template's default.
