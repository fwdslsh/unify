# Firmware 2.4.0

The first release of the year is about honesty in bad conditions.

**The median window is now 40 samples**, up from 16, taken over the same 1.5&nbsp;second
burst. Weed and chop were pulling the old window around by 40&nbsp;mm at two of our test
sites; the wider window holds them inside 8&nbsp;mm without costing measurable battery,
because the transducer was already awake for the whole burst.

**A reading with no echo is now a flag, not a number.** Before this release a burst that
agreed on nothing returned the last good distance, which looked exactly like a river that
had stopped moving. It now sets bit 1 of the flags byte and reports the distance it could
not confirm, so a gateway can tell "unchanged" from "unknown".

The `samples` byte is new in the payload and documented in
[telemetry](/docs/telemetry.html). Upgrading is over the maintenance port; there is no
over-the-air update path and there is not going to be one.
